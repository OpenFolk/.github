# OpenFolk

Open-source tools for working with AI coding agents as teammates — on your own machine, under your own control.

## Projects

| Project | What it does | Status |
|---|---|---|
| **[OpenFolk](https://github.com/OpenFolk/OpenFolk)** | A messenger-style interface for desktop and phone that runs several AI coding agents (Claude Code, Codex and others) on your own computers. Each bot is a colleague with its own name, role, working folder and model. Bots keep working while the app is closed and notify you when they are done or need an approval. | [v0.1.0](https://github.com/OpenFolk/OpenFolk/releases/tag/v0.1.0), first public release |

## Principles

- **Your machine, your data.** Agents run locally. The relay only forwards messages and never sees your credentials or your conversations.
- **Approvals, not surprises.** Risky actions such as deleting, pushing, deploying or touching secrets wait for your explicit OK.
- **Small, readable codebases.** No framework magic; a contributor should be able to read a project in an afternoon.
