# OpenFolk/.github

Organization-wide defaults for all OpenFolk repositories:

- `profile/README.md` — the organization profile shown at <https://github.com/OpenFolk>
- `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md` — community health files inherited by every repository that does not ship its own
- `.github/ISSUE_TEMPLATE/` and `.github/PULL_REQUEST_TEMPLATE.md` — default issue and pull request templates
