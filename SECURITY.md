# Security Policy

We take security seriously. Several OpenFolk projects run AI agents with access to a developer's machine, so a vulnerability can have real consequences for users.

## Reporting a vulnerability

**Please do not open a public issue for security problems.**

Report vulnerabilities through GitHub's private vulnerability reporting: open the **Security** tab of the affected repository and choose **Report a vulnerability**. If that option is not available for a repository, open a report in [OpenFolk/.github](https://github.com/OpenFolk/.github/security/advisories/new) instead and name the affected project.

Please include:

- the affected repository and version or commit
- steps to reproduce or a proof of concept
- the impact you expect

## What to expect

- We acknowledge reports within 5 working days.
- We keep you informed while we investigate and prepare a fix.
- We credit reporters in the release notes unless they prefer to stay anonymous.

## Supported versions

Only the latest release of each project receives security fixes.
